## ⚙️ Local Setup & Running Instructions

To test and run this task locally on your machine:

### Prerequisites
Ensure you have **Node.js** (v16+ recommended) and **npm** installed.

### Steps
1. **Clone the repository:**
   ```bash
   git clone [https://github.com/sarmad-tabassum/portfolio-task-codealpha.git](https://github.com/sarmad-tabassum/portfolio-task-codealpha.git)
Navigate into the project folder:

Bash
cd portfolio-task-codealpha
Install project dependencies:

Bash
npm install
Launch the local development server:

Bash
npm run dev
Open your browser and go to the local URL (e.g., http://localhost:5173).
